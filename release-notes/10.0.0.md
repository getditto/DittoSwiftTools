DittoSwiftTools 10 supports Ditto Swift SDK 5 and requires DittoSwiftPackage 5.0.1 or a later 5.x release.

## Breaking changes

- Ditto Swift SDK 4 is no longer supported.
- A Swift 6.0 or later toolchain is required. DittoSwiftTools remains in Swift 5 language mode; adopting Swift 6 language semantics and strict concurrency is separate follow-up work. (SDKS-3990)
- The minimum supported platforms are now iOS 15, Mac Catalyst 15, and macOS 12. iOS 14 and macOS 11 are no longer supported.
- tvOS and the `DittoTvOSTextFieldComponent` product were removed because DittoSwiftPackage 5 no longer supports tvOS. (SDKS-3944)
- Presence Viewer assets are now included in DittoSwiftTools. Remove any direct DittoPresenceViewerCore package dependency and use the `DittoPresenceViewer` product.

## Public API changes

- `DittoPeerConnection.connectionTypes` reports every observed SDK connection type. The fixed `bluetooth`, `p2pWifi`, and `lan` accessors are deprecated.
- `ExportDataMacOS` is the preferred spelling for the macOS export type. The previously published `ExportData_macOS` name remains as a deprecated alias so existing callers continue to compile.

## Changed

- Migrate support email to support@ditto.com by @bplattenburg in https://github.com/getditto/DittoSwiftTools/pull/202.

## Fixed

- Fixed Data Browser collection discovery and collection-name quoting for Ditto SDK 5. (SDKS-3822)
- Fixed Heartbeat and the Presence Degradation Reporter incorrectly counting WebSocket connections as LAN.
- Made the included DittoToolsApp example self-contained when built from a clean public-repository checkout. (SDKS-3867)
- Restored the Presence Viewer assets used by previous GA tools releases. (SDKS-4488)
