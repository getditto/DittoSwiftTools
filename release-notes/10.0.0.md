DittoSwiftTools 10 is the first major release for Ditto Swift SDK 5. It requires DittoSwiftPackage 5.0.1 or a later 5.x release.

## Breaking changes

- Ditto Swift SDK 4 is no longer supported.
- A Swift 6.0 or later toolchain is required because DittoSwiftPackage 5.0.1 requires SwiftPM 6.0. DittoSwiftTools sources remain in Swift 5 language mode for this release; adopting Swift 6 language semantics and strict concurrency is separate follow-up work. (SDKS-3990)
- The minimum supported platforms are now iOS 15, Mac Catalyst 15, and macOS 12. iOS 14 and macOS 11 are no longer supported.
- tvOS support was removed. The `DittoTvOSTextFieldComponent` library product and target were also removed. (SDKS-3944)
- DittoPresenceViewerCore is now vendored inside DittoSwiftTools instead of resolved as a separate package dependency. Consumers should depend only on the `DittoPresenceViewer` product from DittoSwiftTools.

## Public API changes

- `DittoPeerConnection.connectionTypes` reports every observed connection type using the exact Ditto SDK enum raw value, including WebSocket, Multicast, and connection types added by future SDKs. The fixed `bluetooth`, `p2pWifi`, and `lan` accessors are deprecated in favor of this map.
- The existing `isConnectedToDittoCloud` tools property and heartbeat document field continue to report whether the peer is connected to Ditto Server. The name remains unchanged so tools built with SDK 4 and SDK 5 can exchange heartbeat documents.
- `ExportDataMacOS` is the preferred spelling for the macOS export type. The previously published `ExportData_macOS` name remains as a deprecated alias so existing callers continue to compile.

## Removed

- Removed tvOS support and the public `DittoTvOSTextFieldComponent` product.
- Removed the external DittoPresenceViewerCore package dependency from the published package manifest.

## Added

- Added the open-ended `connectionTypes` map to heartbeat peer documents. The legacy `bluetooth`, `p2pWifi`, and `lan` summary fields remain on the wire so old and new tools can exchange documents.

## Changed

- Updated the published support contact to `support@ditto.com`. See [DittoSwiftTools PR 202](https://github.com/getditto/DittoSwiftTools/pull/202).

## Fixed

- Fixed Data Browser collection discovery and collection-name quoting for Ditto SDK 5. (SDKS-3822)
- Fixed Heartbeat and the Presence Degradation Reporter incorrectly counting WebSocket connections as LAN. The SDK enum's `AccessPoint` case supplies the existing `lan` count; WebSocket remains a separate connection type.
- Made the included DittoToolsApp example self-contained when built from a clean public-repository checkout. (SDKS-3867)
- Published tools continue to use the previously released GA Presence Viewer assets while its newer source and generated bundle are reconciled. (SDKS-4488)
